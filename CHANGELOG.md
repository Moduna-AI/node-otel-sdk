# @moduna/otel

## 1.1.4

### Patch Changes

- Added configurable LangChain callback debug logging and richer LLM telemetry attributes.

## 1.0.0

### Major Changes

- Initial public release of the Moduna OpenTelemetry SDK.
- Added one-line SDK initialization with `import ModunaOTEL from "@moduna/otel"`.
- Added Vercel AI SDK telemetry metadata helpers for per-call conversation and session IDs.
- Added LangChain callback handler support, including global handler registration.
- Added npm package distribution with runtime JavaScript and TypeScript declarations.
